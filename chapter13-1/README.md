# chapter13-1

AgentScope Java 2.0 相关示例。

- `openai-java-sdk-demo`：OpenAI Java SDK 的 OpenAI-compatible 接入，默认 DeepSeek，也支持 Ollama 和 ChatGPT。
- `google-genai-sdk-demo`：Google Gen AI Java SDK adapter，同时保留 DeepSeek、Ollama、ChatGPT 的统一配置入口。
- `anthropic-java-sdk-demo`：Anthropic Java SDK adapter，同时保留 DeepSeek、Ollama、ChatGPT 的统一配置入口。
- `bailian-dashscope-model-demo`：AgentScope Java 2.0 通过 DashScopeChatModel 接入阿里云百炼模型。
- `agentscope-java-2-runtime-demo`：模型配置、`ReActAgent`、`RuntimeContext`、`HarnessAgent` 和迁移差异。
